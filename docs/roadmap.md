# 开发阶段路线图

> 只记录阶段状态和剩余验收，不复制实现、引脚或施工步骤。物理接线以
> [hardware-wiring.md](hardware-wiring.md) 为准，未解决风险以
> [decisions.md](decisions.md) 的 ISS 区为准。

状态：✅ 完成 ｜ 🚧 进行中 ｜ 📋 未开始

任务表规则：

- 每个待办使用稳定 ID；其他任务通过 ID 声明依赖。
- 已完成的 Phase 可直接作为依赖，并视为已满足。
- `依赖` 为 `—`，或所列任务均为 ✅ 时，该任务即可开始。
- 依赖满足且位于不同轨道的任务可以并行；涉及同一实物的 HW/TEST 任务仍需串行验收。
- 轨道缩写：`HW` 硬件、`BE` 后端、`FE` 前端、`AI` 推理、`OPS` 系统网络、`TEST` 验收。
