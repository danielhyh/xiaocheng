### 接线整理施工清单（硬件并行任务）

> 与软件 Phase 并行的硬件整理工程：把当前「一团乱 + 多点死焊」整理成「配电汇流 + 排针插拔」的清爽结构。
> 原则：**先建骨架(配电/共地)，再逐模块归位**；每步可验证，拆之前先记录，绝不一次全拆。
> 引脚/零件细节见 `hardware-wiring.md`。

**总策略（先读这段）**

1. **不要一次全拆。** 当前能跑的(电机/电源/I2C)是你的"已知好状态"，是排查基准。
2. **先做两块万能板的骨架**(Board-A 配电、Board-B 信号)，骨架好了再把模块一个个迁过去。
3. **死焊 → 改插拔。** 凡是「多根线焊一个点」的，改成万能板汇流 + 排针/杜邦线/KF301 端子。
4. **每迁完一个模块就通电验证**，确认正常再迁下一个。坏了也只可能是刚动的那个。

#### 阶段 0 — 准备（30 分钟，别跳过）

- [ ] **拍照存档**：当前接线多角度各拍 2 张(尤其电机、L298N、I2C、电源)，存到手机相册命名"整理前"。
- [ ] **准备工具**：万用表(通断+电压档)、烙铁、热缩管、扎带、记号笔、便利贴。
- [ ] **打印/打开 `hardware-wiring.md` 的第 4 节**(40-pin 分配表) —— 接线时全程对照，是唯一真相。
- [ ] **贴标签**：给每根已接的关键线两端贴便利贴(如"左电机 IN1→Pin11")，拆下来也不会认错。

#### 阶段 1 — 建配电骨架 Board-A（核心，最优先）

> 这一步解决「好多点焊一起」的根因：建立全车唯一的电源/共地汇流点。

- [ ] **规划三条母排**(在万能板上用粗锡或铜线连出三条总线)：
  - 🔴 电池原始轨(7.4V)
  - 🟠 5V 外设轨(LM2596S#2 输出)
  - ⚫ **共地星点**(全车唯一 GND 汇集点)
- [ ] **固定两块 LM2596S** 到 Board-A，先**空载调压**到 5.0V±0.1V(见坑 5)，再接负载。
- [ ] **装 KF301-3P 端子**作为可拆抽头：电池进线、各路 5V/GND/信号抽头。
- [ ] **LM2596S#1 输出侧用 KF301 端子，不焊死**(预留 Phase15 高边开关位)。
- [ ] **共地汇集**：电池GND、L298N、两块LM2596S、ADS1115、PCA9685、OPi 全部接到共地星点。
- [ ] ✅ **验证**：万用表测三条母排电压(电池轨~7.4V、5V轨5.0V、地为0)，确认不短路。

#### 阶段 2 — 信号调理骨架 Board-B

- [ ] **I2C 单组进、板上扇出**：OPi 的 SDA(Pin3)/SCL(Pin5)/3.3V(Pin1)/GND 各一根下到 Board-B，再用排针扇出给 ADS1115、PCA9685。
- [ ] **焊 74AHCT125** 电平转换(灯带信号用，Phase8 再接灯带)。
- [ ] 全部对外接口做成**排针**，模块用杜邦线插拔，不死焊。
- [ ] ✅ **验证**：`i2cdetect -y 1` 应看到 ADS1115@0x48(PCA9685 接入后 0x40)。

> HC-SR04 改用 3.3V 供电、Echo 直连，原 Board-B 上 2 路 Echo 分压(4 颗电阻)已取消（见 hardware-wiring 坑 6）。

#### 阶段 3 — 迁移已接模块（逐个迁，逐个验）

> 顺序：电源 → 电机 → ADC。每迁一个，通电验证 OK 再下一个。

- [ ] **OPi 供电**：LM2596S#1 → KF301 → OPi Type-C。开机正常进系统。
- [ ] **L298N**：电源接电池轨，6 根信号线(ENA7/IN1-11/IN2-13/ENB32/IN3-22/IN4-26)理顺走一侧，GND 接共地。起后端测前后左右。
- [ ] **ADS1115**：I2C 从 Board-B 取，分压输入接电池轨采样点。看遥测电压读数正常。
- [ ] **走线收束**：电源线(红黑)走一侧、信号线走另一侧，用扎带分束，交叉处尽量垂直。

#### 阶段 4 — 接入待接模块（一次只上一个）

> 全部走规整结构。每个接完即验证。建议从最简单的大灯开始找成就感。

- [ ] **大灯**(最简单，3 根线)：正→电池轨、负→共地、信号→Pin33。启用 `pwm15-m2` overlay，测亮灭+调光。
- [ ] **HC-SR04 ×2**：VCC→3.3V、GND→共地、Trig 直连(前29/后35)、Echo 直连(前31/后37，无需分压)。测距读数。
- [ ] **PCA9685 + 双云台**：V+→5V轨、I2C 从 Board-B、4 个 SG90 接 CH0/1(前)、CH3/4(后)。测舵机转动。
- [ ] **WS2812B 灯带**：DATA Pin19→74AHCT125→DIN，5V 走外设轨独立供电。测点亮。
- [ ] **前置 OV13855 摄像头**：装前云台，接 OPi。测画面。

#### 阶段 5 — 收尾

- [ ] 所有线束扎带固定，分层走线(底:电池/中:配电信号/顶:传感云台)。
- [ ] 多余线材剪短或盘整，热缩管包裸露焊点。
- [ ] **拍照存档"整理后"**，对比成就感拉满。
- [ ] 回填本清单勾选状态，更新 `hardware-wiring.md` 第 0 节各模块状态 📋→✅。

**应急回退**

- 任何一步通电异常 → **立即断电**，只检查"刚动过的那个模块"(因为其他都是已验证好状态)。
- 对照"整理前"照片和便利贴标签复原该模块。
- 共地是高频故障源：异常时先用万用表确认该模块 GND 是否真正接到共地星点。
